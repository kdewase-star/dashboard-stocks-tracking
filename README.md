Publish with GitHub Pages
Create a new GitHub repository, for example stock-dashboard.
Upload index.html to the repository root.
Open Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select branch main and folder / (root).
Save.
After GitHub finishes deploying, your dashboard will be available at:
https://YOUR-USERNAME.github.io/stock-dashboard/
Replace YOUR-USERNAME with your GitHub username.
Notes
This is a static dashboard and does not require Upstox, Groww, Zerodha, or any broker credentials. Market data is delayed/public and can be refreshed from the dashboard.

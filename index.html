Data architecture: Your browser no longer calls a finance API. A GitHub Actions job periodically fetches delayed public market data and writes data.json into this repository. The dashboard reads that local file, which avoids the CORS/proxy problem that caused the V4 “Starting…” issue. GitHub Actions scheduled workflows can run on a cron schedule; GitHub notes that schedules can occasionally be delayed under load.
